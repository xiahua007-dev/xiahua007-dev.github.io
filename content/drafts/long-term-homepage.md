## 写作方向

这篇文章会记录个人主页从“能访问”到“值得长期维护”的过程。

重点不是介绍工具清单，而是说明为什么选择 GitHub Pages、如何组织内容入口、哪些地方适合先上线再迭代。

## 计划覆盖

- GitHub Pages 与自定义域名
- 首页信息结构
- 项目、写作、联系方式的长期维护方式
- 后续从静态页面升级到文章系统的边界
